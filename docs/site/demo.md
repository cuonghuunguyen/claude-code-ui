# claude-code-ui in 40 seconds

<video class="demo-video" src="/promo.mp4" poster="/promo-poster.jpg" controls playsinline preload="metadata" width="1280" height="720"></video>

A 40-second video of claude-code-ui. It shows the install, sessions, the git graph, the command palette, workers and phone notifications.

## What the video shows

1. **Install:** `npx claude-code-ui` prints a link and a QR code. See [Install & first run](./guide/install).
2. **Sessions:** many Claude Code sessions in tabs, grouped by project. See [Sessions & tabs](./features/sessions).
3. **Git graph:** branches and commits next to the chat. See [Git graph](./features/git-graph).
4. **Command palette:** every action from the keyboard. See [Command palette](./features/palette).
5. **Workers:** one session starts and drives others. See [Orchestration](./features/orchestration).
6. **Phone notifications:** a push when a session needs you. See [Notifications](./features/notifications).
