# Focus page

One page that shows, per session, what needs you, what is working and what finished while you were away. Requests are answered right there.

## How to use

1. Open **Focus**: the row at the top of the sidebar, or the pinned **Focus** tab. The number shows how many sessions wait for an answer.
2. **Needs you** lists the requests, then sessions that need a look. Pick a row (click or arrow keys).
3. Answer a request in place, the same way as in the session: **Allow once**, **Allow always**, **Deny**, or answer the question.
4. Press **Next waiting** (or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↓</kbd> from anywhere) to jump to the next request.
5. **Working** shows what each running session does now and, with a task list, its progress ("2 of 5"). Click a row to open the session.
6. **Finished while you were away** lists sessions that ended a turn since you last looked, with the last line of the answer and the task summary.
7. On a **Usage limit** row, **Cancel continue** stops the scheduled continue.

## Good to know

- Rows come in a fixed order: escalated, permission, question, error, usage limit, quiet. The header says how many need you, how many to review and how many work.
- **Quiet** is information, not an alarm: a running session with no event for 5 minutes and no running tool. Check it, it may be fine.
- Each list shows 5 rows and **+N more**.
- Error and finished rows go away when you open the session. Finished rows also go after 24 hours.
- The number on the tab and the title counts only sessions that wait for you (escalated, permission, question).
- The usage-limit row shows only while auto-continue is on.
- Answered requests shrink to one line until you leave the page.
- Each request gets a **tier**. **Low** is a plain read (or, in some repos, an edit) inside the session's folder. Everything else is **high**. A high one shows **High tier · always asks** and has no **Allow always** here. Only you can answer it (see [Orchestration](orchestration)).
- **Escalated by coordinator** marks a worker's request that its coordinator handed to you.
- You can also open it with the link `#focus`.
- While Focus is open, [in-app notifications](notifications) for requests are hidden: you already see them here.
