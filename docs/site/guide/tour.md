# A quick tour

The screen has four parts. Each links to its own page.

![The main screen: sidebar, tabs, session and side panel](/screenshots/workspace-light.png)

| Part | Where | What it is |
| --- | --- | --- |
| **Sidebar** | Left | Your [projects](../features/projects) and their [sessions](../features/sessions). Search, Focus and Settings live here too. |
| **Tab bar** | Top | Open sessions as [tabs](../features/sessions#tabs), grouped by project. |
| **Session** | Middle | The chat with Claude: the [timeline](../features/timeline) and the [prompt box](../features/prompt-box) at the bottom. |
| **Side panel** | Right | [Files](../features/files), [Changes](../features/changes), [Graph](../features/git-graph) and the [terminal](../features/terminal). |

## Words you will see

- **Daemon:** the small server claude-code-ui runs on your computer. It owns all sessions.
- **Project:** a folder you opened with **Open project**.
- **Session:** one conversation with Claude in one folder.
- **Turn:** one prompt and everything Claude does for it.
- **Tool card:** one thing Claude did, like running a command or editing a file.
- **Permission request:** Claude asks before it runs a tool. See [Permissions & modes](../features/permissions).

## Top-right buttons

| Button | Does |
| --- | --- |
| Usage ring | Your plan usage. Click for details. See [Usage & context](../features/usage). |
| Search | Opens the [command palette](../features/palette). |
| Theme | Cycles System → Light → Dark. |
| Panel | Shows or hides the side panel. |

## Good to know

- Press <kbd>Ctrl</kbd>+<kbd>/</kbd> to see every [keyboard shortcut](../reference/shortcuts).
- Restart the guided tour any time: **Settings › Guide**, or "Show guide" in the command palette.
- On a phone the layout changes: the sidebar becomes a drawer and you see one pane at a time.
